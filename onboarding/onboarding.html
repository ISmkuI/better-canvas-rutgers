PotatoCanvas Rutgers
新手引导 · 一分钟配好

👋 欢迎使用 PotatoCanvas

给 Rutgers Canvas 加上这些东西：

  • 🎨
    外观主题十来个预设风格（暗夜 / 清新 / 像素风 / 赛博朋克…），还能自己调色、换背景。
  • 🃏
    卡片成绩与班级均分课程卡旁直接看总评、GPA、班级均分和 Section，不用一门门点进去。
  • 📊
    仪表盘面板本周截止、期中期末倒计时、今日课程、最新消息，都放在仪表盘顶部。
  • ✨
    学习助手（可选）选中文字提问、页面对话、闪卡、练习题。需要自备模型 API key，只从你的浏览器直连。

🎨 选一个外观

点一下就生效，之后随时可以在设置里换。

📊 仪表盘

这些默认都是开着的，不想要的关掉即可。

提示：仪表盘功能需要经典的卡片式仪表盘。如果你的 Canvas 首页是列表 / 最近活动视图，点右上角「⋮」→「Switch to old dashboard view / Card View」。

✨ 学习助手（可选）

填一个模型服务的 API key 就能用。现在不想填也没关系，之后在设置的「✨ 助手」里随时补。

✓ 已保存

隐私：key 只保存在你这台浏览器的扩展存储里，不经过任何中间服务器。只有你主动提问时，选中的文字 / 页面内容 / 截图才会发给你选的这家模型服务。

🎉 配好了

接下来：

  1. 打开 Canvas 仪表盘所有功能都在那里生效；第一次进去会有一个页内导览。
  2. 右下角 ⚙ 是完整设置外观微调、面板排序、消息关键词、期中期末日期、助手模型都在里面。
  3. 工具栏图标是快速开关主题 / 卡片成绩 / 面板 / 消息铃铛一键开关，还有清缓存。
